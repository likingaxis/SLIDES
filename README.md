# VulcaTest — Presentazione di laurea

Presentazione di Luca Gugliotta, Università degli Studi di Roma Tor Vergata.

**[Apri le slide](https://likingaxis.github.io/SLIDES/)**

## Utilizzo

- Frecce destra e sinistra: avanzamento e ritorno, comprese le animazioni.
- `Esc`: panoramica delle slide.
- `S`: vista relatore, con note e tempi. Il browser può richiedere di consentire la finestra.

Il file principale è `presentazione.html`. Le immagini e le librerie sono incluse in locale; la presentazione può essere aperta anche offline.

## Pubblicazione

GitHub Pages pubblica la cartella principale del branch `main`. Per aggiornare le slide, sostituire il file principale e gli eventuali asset modificati, quindi effettuare il push.

## Risorse

Presentazione basata su reveal.js e KaTeX. Icone Phosphor duotone: licenza MIT in `img/phosphor/LICENSE.txt`. Loghi e altre risorse restano dei rispettivi titolari.
